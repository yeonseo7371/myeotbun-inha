# 몇분인하 — 내 주소로 올리는 법

폴더 구성
- index.html        랜딩페이지 (버튼이 ./app/ 으로 연결됨)
- app/index.html    시연 앱
- package.json      Railway용 (GitHub Pages에는 필요 없음)

## 방법 1. GitHub Pages — 제일 쉬움, 무료, 5분
1. github.com 가입/로그인 → 오른쪽 위 + → New repository
2. 이름 예: myeotbun-inha, Public 선택 → Create repository
3. "uploading an existing file" 링크 클릭 → 이 폴더의 파일을 전부 끌어다 놓기
   (중요: app 폴더째로 끌어넣으면 폴더 구조가 유지됨) → Commit changes
4. 저장소 Settings → 왼쪽 Pages → Branch를 main, 폴더 (root)로 → Save
5. 1~2분 뒤 같은 화면에 주소가 뜸: https://아이디.github.io/myeotbun-inha/
   그 주소가 랜딩이고, 버튼을 누르면 앱이 열림

## 방법 2. Railway
1. 위 1~3처럼 GitHub 저장소를 먼저 만든다
2. railway.app → New Project → Deploy from GitHub repo → 저장소 선택
3. 배포가 끝나면 Settings → Networking → Generate Domain → 주소 완성

## 발표 팁
- 폰에서 주소를 열고 브라우저 메뉴의 "홈 화면에 추가"를 누르면
  아이콘이 생기고 주소창 없는 전체 화면으로 열려서 설치된 앱처럼 보임
